{% icon "share" %} Set up the Shortcut {% icon "chevron-down" 18 %}

About five minutes, once per iPhone. You need your key and this address:

  1. Open Shortcuts, tap + and name the new shortcut Send to LifeOS.
  2. Tap the ⓘ button and turn on Show in Share Sheet. Then tap the blue Any in the first action and keep only Files, Images, PDFs and Text.
  3. Add Ask for Input. Set the prompt to What should LifeOS do with this? You can leave the answer blank when you use it.
  4. Add Repeat with Each and set it to Shortcut Input. Inside the repeat:
    1. Add Get Details of Files and set it to get the File Extension of Repeat Item.
    2. Add If: File Extension is heic.
    3. Under If, add Convert Image (Repeat Item to JPEG), then Add to Variable with the converted image and the variable name Items.
    4. Under Otherwise, add Add to Variable with Repeat Item and the variable name Items.
    iPhone camera photos are HEIC, which LifeOS can’t read, so this turns them into JPEGs and leaves everything else alone.
  5. After End Repeat, add Get Contents of URL and paste the address above. Tap › to show more options, then:
    • Method: POST.
    • Headers: add Authorization, and paste your key as its value.
    • Request Body: Form. Add a Text field called message set to Provided Input, and a File field called file set to the Items variable.
  6. Add Show Notification and set it to Contents of URL. That shows “Sent to LifeOS” or what went wrong.

To use it, tap Share on a document, photo or message, then choose Send to LifeOS. The reply appears in your Ask chat.

If you type what you want (for example remind me to pay this on Friday), new reminders, tasks, notes and events are added straight away. Changes to things that already exist, Homebase changes, and anything from a share where you left the question blank wait for you to confirm in Ask.

To give the Shortcut to someone else, duplicate it and clear the Authorization value before you share the copy. They make their own key here when signed in as themselves.
